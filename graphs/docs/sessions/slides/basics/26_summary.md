# Summary

| Concept         | Meaning                                    |
| --------------- | ------------------------------------------ |
| Node (Vertex)   | Entity in graph                            |
| Edge            | Connection between nodes                   |
| Path            | Sequence of connected nodes                |
| Cycle           | Path starting and ending at same node      |
| Connected Graph | Every node reachable from every other node |
| Component       | Connected part of a graph                  |
| Tree            | Connected graph with `n−1` edges           |
| Directed Graph  | Edges have directions                      |
| Weighted Graph  | Edges have weights                         |
| Degree          | Number of neighbors                        |
| Indegree        | Incoming edges                             |
| Outdegree       | Outgoing edges                             |
| Regular Graph   | Same degree for every node                 |
| Complete Graph  | Every pair connected                       |
| Bipartite Graph | Two-colorable graph                        |
| Simple Graph    | No loops or parallel edges                 |
